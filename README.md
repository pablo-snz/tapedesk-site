# tapedesk-site

Public marketing + privacy site for **TapeDesk** — a 4-track tape recorder for iPhone.

- `index.html` — landing page
- `privacy.html` — privacy policy (App Store support/privacy URL)

Deployed to GitHub Pages on every push to `main` via `.github/workflows/pages.yml`.

Live: https://pablo-snz.github.io/tapedesk-site/
